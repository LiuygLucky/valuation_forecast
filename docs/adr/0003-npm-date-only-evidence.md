# ADR 0003：NPM 日期精度与公开浏览器证据

页面 As of 日期表示指标有效日，不能据此推断精确发布时间或13:00 ET更新。observed_at保存实际读取时刻，effective_date单独保存，SourceVersion捕获/first_seen为实际入库时刻。published_at是首次可证实公开可见的采集时刻，其语义在public_time_basis标注，非声称原始发布时间。

日期精度锚点与同纽约日新闻的先后关系未知，alpha=0；早于有效日的新闻保守视为可能吸收；晚于有效日的新闻不因晚采集而自动吸收。锚点选择优先有效日期，再比较观测与入库时刻。

默认Playwright只读取固定公开URL，不绕过403、登录或付费墙。普通浏览器能访问时允许显式导入原始截图、DOM和真实采集元数据，未知HTTP状态保持null。哈希保证存档一致性，不独自证明网页真实性；本次额外视觉复核截图。每次预测将证据复制进不可变快照，离线重放无需活网页或原始目录。

真实LIVE允许外部数据失败后使用已有合格锚点，但明确记录NPM_FETCH_BLOCKED、BASELINE_ONLY、UNCALIBRATED。本次没有可入模的新闻正文，未为调用LLM而伪造证据。
